How the prototype works.

What the prototype does today, and what it does not. It has not been reviewed by a security expert and is not for real use.

What it does not do

  • ✗No AI. The earlier AI classifier was removed. It had only been tested against a keyword mock.
  • ✗No cloud backup or sync. Evidence stays on the phone. If the phone is lost, so is the evidence.
  • ✗No law mapping. The GD draft does not pick legal sections for you. Ask a lawyer or PCSW.
  • ✗No court certificate. The file hashes are not a certificate of authenticity, and no lawyer has reviewed whether the output would be accepted in court.
  • ✗No police integration. There is no e-GD API. You file the draft yourself.

What it does

SMS SOS

Sends one SMS with your location over the mobile network, so it works without mobile data. Delivery is not guaranteed, and the SMS permission limits Play Store distribution.

Duress PIN & decoy vault

A separate duress PIN opens a decoy vault with its own database file and key. A wipe code that you choose triggers the vault wipe. Neither has been tested on a real phone.

File hashes

The app records the SHA-256 of each original file (or note text) before it encrypts anything, and lists it in the GD draft. Anyone with the same file can recompute it. A match shows the file is unchanged; it does not show who made it, or when. Times come from the phone's clock.
