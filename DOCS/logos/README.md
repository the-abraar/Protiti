# Protiti Logo & App Icon Assets

## Icon Strategy: Dynamic Disguise

Protiti uses a dual-persona icon strategy, which can be toggled via OS-level launcher aliases (`<activity-alias>` in Android, `setAlternateIconName` in iOS).

### 1. Default Persona: Wellness & Journaling
By default, the app presents a trauma-informed, calming interface. It masquerades as a safe space (a journal or wellness app) to avoid looking like a high-alert security app. 
* **Assets Provided:**
  * `default_wellness_lotus.jpg` - A geometric lotus forming a soft shield.
  * `default_journal_ribbon.jpg` - An elegant journal featuring a Bengali "Pa" (প) ribbon lock.

### 2. Stealth Persona: Utility / Math (Toggleable)
If the user is in a high-risk situation where an abuser monitors their phone, they can toggle the app icon from settings. The app will swap its launcher icon and name to look like a standard calculator or utility.
* **Assets Provided:**
  * `stealth_lens.jpg` - Overlapping circles resembling a generic utility or camera lens.
